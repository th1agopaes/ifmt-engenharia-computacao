## 📌 Ementa

> O projeto deve ser desenvolvido de acordo com o estabelecido pelo docente da disciplina, e deve seguir as seguintes diretrizes: 1) Atender o limite de tempo estabelecido no início do semestre, 2) Envolver um estudante por projeto, de forma individual, ou se houver justificativa e o docente assim o permitir, mais de um estudante poderá estar vinculado a cada projeto, 3) Apresentar os resultados do projeto na forma de artigo ABNT, com a devida revisão bibliográfica, 4) Utilizar linguagem clara e objetiva, bem como gráficos e figuras de alta qualidade, 5) Empregar, no desenvolvido do projeto, a linguagem de programação Python, ou outra que vier a substituí-la, e estar bem documentado. Linguagem de Programação: Python
