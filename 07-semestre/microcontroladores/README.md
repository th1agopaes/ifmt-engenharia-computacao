## 📌 Ementa

> Arquiteturas de microprocessadores. Programação de microprocessadores: tipos e formatos de instruções, modos de endereçamento. Memória. Entrada/Saída. Dispositivos periféricos, interrupção, acesso direto à memória. Barramentos padrões. Ferramentas para análise, desenvolvimento e depuração. Projetos com microcontroladores.
