## 📌 Ementa

> Transformada de Laplace. Introdução aos sistemas de controle. Modelagem matemática de sistemas físicos por meio de equações diferenciais ordinárias lineares. Diagrama de Blocos. Diagrama de Fluxo de Sinais. Representação de sistemas de controle no espaço de estado. Análise de sistemas de primeira ordem, de segunda ordem e de ordem superior. Parâmetros de desempenho. Estabilidade pelo critério de Routh-Hurwitz. Análise do lugar das raízes. Projeto de controladores utilizando o método do lugar das raízes. Controladores PID. Técnicas de Sintonia de PID
